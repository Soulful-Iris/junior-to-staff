AI-generated-code trust ("vibe coding") flagged in next-steps, not a category. (Check if final vs RC.)

SUPPLY CHAIN 2025-26 EVENTS: Shai-Hulud Sept 15 2025 = FIRST self-propagating npm worm: postinstall harvested creds (TruffleHog), exfil to public GitHub repos named "Shai-Hulud", used stolen npm tokens to republish malicious versions of victim's packages. CISA alert Sept 23 2025. Shai-Hulud 2.0 Nov 24 2025: 796 packages / 20M+ weekly downloads, ran at PREinstall. Responses now considered practice: pnpm minimumReleaseAge (default 1440min=24h in pnpm 11; rationale: registry removes malware in hours, cooldown skips the window), lockfiles committed + policy-checked (pnpm 11.1.3 checks lockfile entries vs policy), trustPolicy no-downgrade (detects weakened publishing auth), blockExoticSubdeps. Bun has opt-in cooldown; npm CLI has NO cooldown feature. Lockfile protects installs, not upgrades — cooldown covers that gap.

OBSERVABILITY COST: "Observability 2.0" (Charity Majors/Honeycomb): wide events (one arbitrarily-wide structured event per unit of work, hundreds of fields), single columnar store, derive metrics/traces/logs at QUERY time. Cost argument: 1.0 model pays to store same data per-pillar per-use-case; cardinality changes can multiply Datadog bills overnight ($150k->$1M anecdote); "world-class o11y teams spend most time governing cardinality" (Pragmatic Engineer interview Jan 2025). Startups post-2021 nearly all build on wide events + columnar DBs. Honeycomb "Cost Crisis in Observability Tooling" is the reference essay.

DATA: Kafka 4.0 (March 18 2025): ZooKeeper REMOVED, KRaft only (metadata in __cluster_metadata raft topic); 3.9 = last ZK version, must migrate via 3.x bridge; KIP-848 new consumer rebalance protocol (incremental), KIP-932 Queues for Kafka early access. Exactly-once: idempotent producer (PID+seq per partition) + transactions + read_committed; commit offsets in same txn. Rule: Kafka EOS for Kafka-side atomicity (streams), destination idempotency for cross-system.

Senior-craft research, part 4 (data failure modes, perf/cost, provenance):

DATA/SCALE ORDER: What breaks first is NOT the database engine: connection management, query shape, read pressure, failover behavior break before storage/compute limits. Practical order: fix queries/indexes -> cache (with stampede protection) -> read replicas (own the staleness) -> shard LAST (own shard key, fanout, rebalancing). Each fix trades a resource limit for a new failure class. Cache stampede prevention canon: single-flight/locking (lock TTL > recompute time), stale-while-revalidate, TTL jitter, warming; Cloudflare "sometimes I cache" = lock-free probabilistic early refresh. Monitor: hit ratio >95% on hot paths; origin QPS spiking with misses = broken single-flight. Sharding: Postgres has no native sharding — Citus/PgDog/Vitess-for-PG (PlanetScale Postgres 2025) or app-level; don't shard before tuning hardware/queries; real example: Gadget sharded core PG pre-BFCM-2025 splitting control plane vs data plane. "Sharded is not distributed" (YDB blog) is a good corrective.

PERF/COST: Continuous profiling now "4th signal": eBPF agents (Parca ~19Hz/core, Grafana Pyroscope alloy) as DaemonSet <1% CPU overhead — always-on prod profiling normal. Diff flamegraphs red/green between versions; some teams fail deploys on CPU/alloc regression thresholds. Brendan Gregg AI flame graphs (2024). Profiles = the cost signal: 20-30% waste on hot paths common claim; 10-15% infra cost cuts via flamegraph hotspot fixes reported. FinOps: FOCUS spec (v1.3) standardizes billing data; allocation via tags/namespaces; profiling closes shared-cluster attribution gap. Grafana Cloud ships flamegraph AI explainer.

PROVENANCE: npm trusted publishing w/ OIDC GA July 31 2025 (GH Actions hosted + GitLab.com runners, npm CLI >=11.5.1; auto-provenance, no --provenance flag). CAVEAT worth teaching: legacy classic token bypasses it all (Axios attack). PyPI attestations (PEP 740) GA Nov 2024, Sigstore keyless (Fulcio+Rekor), default in gh-action-pypi-publish >=1.11.0; Integrity API. SLSA v1.2 approved Nov 2025 — Source track promoted from experimental; GitHub Artifact Attestations = SLSA Build L2 default, L3 w/ reusable workflows; realistic team target = SLSA L2. SBOM: CISA "2025 Minimum Elements" draft Aug 22 2025 (updates 2021 NTIA: adds component hash, license, tool name, generation context); EU CRA (2024) mandates SBOMs; EO 14028 for US fed sales.

But 57% orgs still phishable primary auth. OAuth 2.1 STILL an IETF draft (draft-ietf-oauth-v2-1-10+), not RFC — but adopted ahead of ratification (MCP auth spec builds on it): PKCE mandatory for all code-flow clients, implicit + password grants removed, exact-match redirect URIs.

AUTHZ: Two camps: policy engines (OPA/Rego infra-wide but Rego learning curve; Cedar = analyzable/automated-reasoning, RBAC+ABAC) vs relationship graphs (Zanzibar-style: SpiceDB, OpenFGA CNCF incubating, Ory Keto) which win at "list everything user can see" reverse queries + billions of objects. Known ReBAC gap: no context/time in check(user, relation, object). Choice = query patterns + latency budget + consistency.

SECRETS 2026: The hierarchy: (1) don't have secrets — workload identity federation/OIDC (GH Actions token -> STS exchange, no stored key, kills secret-zero problem), (2) dynamic short-lived from Vault/cloud SM, (3) static w/ rotation + audit as last resort. GitGuardian: 64% of creds leaked-and-valid in 2022 were STILL ACTIVE Jan 2026; AI-assisted commits leak secrets ~2x baseline; AI-service credential detections +81% YoY. Push protection/pre-commit scanning standard. K8s Secrets are base64 not encryption. Prod/dev secret separation (OWASP cheat sheet).

DELIVERY/DORA: DORA 2025 renamed "State of AI-assisted Software Development" (~5000 respondents): AI = amplifier not fixer; 2025 reversal — AI adoption now positively correlates with throughput (2024 it hurt) BUT still correlates with instability (change failures, rework); AI exposes downstream bottlenecks (review, testing, QA). Senior-craft research, part 6 (AI x design docs, load shedding, otel sampling):

AI x SYSTEM DESIGN (the big 2-year change): code generation cost -> ~0, so bottleneck moved to design judgment + review. "When code becomes cheap, design becomes more valuable... specs are coming back." Faros AI telemetry under high AI adoption: PRs +51% larger, bugs/PR +54%, median PR review time +441%, 31% more PRs merged with NO review — "senior engineer tax"; fix is upstream (better specs/context to the AI), not out-reviewing it. Help Net Security June 2026: leaders rate AI code higher quality but it behaves worse in prod; SRE/DevOps losing up to 1/3 of week to triaging machine output. IEEE Spectrum (McLaren Stanley, Amazon): work shifted to writing specifications before generation. AI drafts design docs/ADRs now; senior reviews grounded drafts; ADR corpus can't keep up with system change rate. DORA 2025: AI amplifies existing team quality, exposes downstream bottlenecks.

GRACEFUL DEGRADATION canon: Netflix prioritized load shedding. 2020 (Zuul gateway): requests scored 1-100, buckets NON_CRITICAL/DEGRADED_EXPERIENCE/CRITICAL, dynamic priority threshold, cubic throttling curve, validated w/ ChAP chaos experiments. 2024 service-level post: 4 buckets a la Linux tc-prio — CRITICAL / DEGRADED / BEST_EFFORT / BULK, shed on CPU utilization; real win: 12x prefetch spike post-outage, user-initiated availability stayed >99.4%. QCon SF 2025: shedding moved into Envoy sidecar; retry-storm mitigation; continuous chaos load tests. Framing: rate limit -> backpressure -> shed (emergency brake).

OTEL SAMPLING/COST: start head sampling (simple), add tail sampling for keep-all-errors/slow (>2s)/10%-rest policies (OR-combined). Tail sampling REQUIRES all spans of a trace on same collector: two-layer collector topology w/ loadbalancingexporter keyed by traceID — most common quiet production failure is skipping this. decision_wait ~2-3x p99. Compute span metrics BEFORE sampling so RED metrics reflect all traffic. Turn off low-value auto-instrumentation (fs ops, DNS, health checks). Teams need written instrumentation guidelines (span-per-function vs http-only vs 50-attrs chaos). W3C Trace Context default.
