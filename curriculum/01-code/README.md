# Coding and problem solving

<section class="chapter-context" markdown="1">

## Trace small inputs and justify each change

Begin with the state and operations behind a small input. A repeated ID, a dependency cycle, and a moving window are small enough to trace completely. Then solve unfamiliar coding problems before using AI to make and review bounded code changes.

You finish this part able to state a contract, walk an implementation, explain time and memory, and judge an AI-assisted change without giving up responsibility for the result. Python and TypeScript examples are supplied.
