# System evolution and leadership

<section class="chapter-context" markdown="1">

## Change a live system without losing its contract

A storage migration or a cross-team platform decision changes more than one component. These chapters keep the user’s outcome visible while data, clients, ownership, and rollout responsibilities change.

Explain authority, compatibility, repair, rollback, and retirement where they matter. Finish with decisions other engineers can implement and maintain.
