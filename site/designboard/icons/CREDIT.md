# Icons

These are AWS Architecture Icons (package dated 07312026), downloaded from
<https://aws.amazon.com/architecture/icons/>, where AWS writes: "We allow
customers and partners to use these toolkits and assets to create architecture
diagrams." The design board uses them for exactly that: a reader drawing an
architecture diagram.

They are copied unmodified by `../tools/curate_icons.py`, which reads each
icon's path inside the package from `../catalog.json`. Do not recolour, crop or
redraw them; replace them by re-running that script against a newer package.
